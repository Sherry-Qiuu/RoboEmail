# 宣传视频脚本

> 90 秒主版本 + 30 秒短版本。录屏为主，配文字幕与旁白。所有操作都在线上 https://rbem.online 完成。

---

## 拍摄前

| 项 | 建议 |
| --- | --- |
| 分辨率 | 1920×1080，浏览器缩放到 100% |
| 主题 | 浅色（Edge 面板左下角可切），深色留给封面 |
| 账号 | 提前注册好，UNNC 开关打开，配额充足 |
| 数据 | 教授页需要账号勾选 UNNC；历史页先攒 3–4 条记录 |
| 鼠标 | 移动要慢，点击前停 0.3 秒，别乱晃 |
| 隐私 | 录制前清空浏览器的用户名自动填充，避免露出真实邮箱 |

## 主版本 · 90 秒

### 00:00–00:08　开场

**画面**：首页——登录页，光标停在「注册」标签上，停留两秒，再点开。

**字幕**：写给教授的英文邮件

**旁白**：
> 在宁诺，给教授写邮件，难的不是语法，是拿不准该多客气。

---

### 00:08–00:12　登录

**画面**：注册 → 收验证码 → 登录（这一段可以剪成 3 秒快放）。

**字幕**：一个邮箱就能用

**旁白**：
> 注册一个邮箱账号，所有功能都在这一页后面。

---

### 00:12–00:38　写邮件

**画面**（依次）：

1. 停在「写邮件」页，光标依次点过「询问信息」「约时间」两个标签 —— 两个同时亮起
2. 在「背景」框里用中文敲：`这周五要交 COMP1033 的 coursework，但课程页上没写几点截止`
3. 「你希望对方做什么」敲：`确认截止时间`
4. 点「生成」，等结果
5. 结果出来后，鼠标沿着中英对照的段落慢慢划过
6. 停在一个 `{{module_code}}` 占位符上，高亮

**字幕**：目的可以多选 · 背景用中文写 · 缺的信息留成占位符

**旁白**：
> 目的可以选好几个，一件事说一次就够。
> 背景直接写中文，它会替你换成英国学术场合的说法。
> 你没有提供的信息，它不会编，会留一个占位符提醒你补。

---

### 00:38–00:58　润色

**画面**：

1. 切到「润色」，贴一段故意写得不地道的英文草稿
2. 点「更简洁」标签，再在输入框里敲 `别太卑微`
3. 点「开始润色」
4. 结果页：鼠标依次停在每条改动上，让「原文 → 改后 → 理由」被看清
5. 鼠标移到「继续改」，勾一个「更礼貌」，点「再润色一次」

**字幕**：每处改动都有理由 · 标签和自由输入可以叠加

**旁白**：
> 已经写好的草稿，贴进来。
> 它给你改后的版本，也告诉你每一处为什么改。
> 觉得还不够，选中方向，再说一句自己的要求，可以一直改下去。

---

### 00:58–01:12　教授档案

**画面**：

1. 点「教授」，搜索框输入 `Chen`
2. 列表滚动，点其中一行，弹出档案卡
3. 鼠标停在照片、职称、研究方向、第一篇论文的标题上
4. 点「写邮件」，跳到写邮件页，称呼已经填好

**字幕**：五百多位老师 · 研究方向与近期论文

**旁白**：
> 五百多位老师都在里面，研究方向、近期论文、邮箱都查得到。
> 点「写邮件」，称呼会自动填对——教授是 Professor，其余是 Dr。

---

### 01:12–01:24　历史与学习

**画面**：

1. 切到「历史记录」，鼠标停留在列表上，点开「导出」下拉，展示 Word / PDF / HTML 三项后关闭
2. 切到「学习」，停在错题列表和统计图上

**字幕**：历史留在本地 · 错题收进学习页

**旁白**：
> 写过的东西都在本地留一份，可以导出成 Word、PDF 或者网页。
> 改出来的错，会攒进学习页，按类别归档。

---

### 01:24–01:30　收尾

**画面**：回到写邮件页，画面缓缓淡出，中心浮出网址。

**字幕**：rbem.online

**旁白**：
> 让每一封信，读起来都像样。

## 短版本 · 30 秒

给朋友圈、群聊用，不要旁白，纯字幕 + 环境音。

| 时间 | 画面 | 字幕 |
| --- | --- | --- |
| 0–4s | 登录页 | 给教授写邮件，不用再纠结语气 |
| 4–12s | 选两个目的 → 中文背景 → 生成 → 中英对照 | 中文写背景，出来就是英式邮件 |
| 12–20s | 贴草稿 → 勾「更简洁」→ 结果页逐条理由 | 改完还告诉你为什么这么改 |
| 20–27s | 教授档案卡 → 点写邮件 → 称呼已填 | 五百多位老师，称呼自动对 |
| 27–30s | 网址 | rbem.online |

## 录制清单

- [ ] 录屏前把浏览器书签栏隐藏（`Ctrl+Shift+B`）
- [ ] 关掉所有通知（系统 + 微信 + 邮件弹窗）
- [ ] 账号已登录、UNNC 已开、当天配额还有剩
- [ ] 历史记录里已有 3 条以上，导出的下拉能点开
- [ ] 教授页搜索结果不为空（用 `Chen` 或 `Li` 试一次）
- [ ] 「生成」那一步预留 8–10 秒等待，剪的时候可以压缩
- [ ] 结尾网址停留至少 2 秒，方便截图传播

---

## 旁白录制

- 语速比日常说话慢一档，每句之间留 0.5 秒空隙便于剪辑
- 一段一次录，不要一句一句拼，语气会断
- 关键词重读：**多选**、**中文**、**为什么**、**自动填对**
- 背景音乐选无旋律的轻电子或钢琴，音量压到 -24 dB 左右，别盖过人声

---

## 几条不要说的话

宣传里避免这几类表述，容易被当成承诺：

- 「完全准确」「保证不会出错」——模型会犯错的
- 「免费」——服务器和模型都有成本，现在是校内自用，不要写"永久免费"
- 「一键搞定所有邮件」——它只做学生写给老师的这一种
